# Сервис цветов2 сайт

# Анализ проекта и сводка

## Что публикуется

**Монорепозиторий** лэндинга для продажи цветов, состоящий из 4 агентов/сервисов:

| Сервис | Назначение |
|---|---|
| `ba_agent` | Бизнес-анализ и документация требований |
| `content_agent` | Генерация/управление контентом |
| `frontend_agent` | React/TS фронтенд (компоненты, типы, данные) |
| `backend_agent` | FastAPI бэкенд (БД, модели, уведомления, роутеры) |
| `payment_agent` | Платёжный модуль (конфиг, зависимости) |

---

## Сводка для корневого README.md

```markdown
# 🌸 Flower Shop — Лэндинг для продажи цветов

Проект представляет собой полностековое веб-приложение для онлайн-продажи цветов.
Архитектура построена по агентному принципу: каждый модуль (frontend, backend, payment, content)
независим, имеет собственные зависимости и документацию. Фронтенд реализован на React + TypeScript,
бэкенд — на FastAPI с поддержкой ORM и системой уведомлений.

Платёжный модуль (`payment_agent`) интегрируется с внешними платёжными шлюзами
и вынесен в отдельный сервис для соответствия требованиям безопасности PCI DSS.
Конфигурация чувствительных данных (токены, ключи API, строки подключения к БД)
вынесена в `.env`-файлы — в репозиторий попадают только `.env.example`-шаблоны
без реальных значений.

Для запуска проекта локально потребуется Python 3.10+, Node.js 18+ и настроенные
переменные окружения по образцу `.env.example` в каждом из сервисов.
Подробная документация по каждому модулю находится в соответствующих `README.md`.
```
